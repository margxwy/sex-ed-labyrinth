Fixel Display 1.211 — WebFonts distribution package
Prepared: 2026-10-15

Official website: https://fixel.macpaw.com/
Official FAQ: https://fixel.macpaw.com/frequently-asked-questions
Official release archive: https://fonts.macpaw.com/fonts/FixelAll.zip
Archive SHA-256: 0844174a94258e3e035bdd906b6b85961a130cc8cc6368d4d7503d49260987fe

18 original Display styles: Thin, ExtraLight, Light, Regular, Medium,
SemiBold, Bold, ExtraBold, Black, each upright and italic, in OTF and WOFF2.
All 36 static binaries are byte-identical to the official archive.
Only external file paths were changed to match the site's conventions:
RegularItalic is named Italic. Embedded font names remain unchanged.
Old static TTF files from version 1.000 are not included.

Two original variable TTF files are also included, with external filenames
FixelDisplayVariable and FixelDisplayVariableItalic. Their contents are
byte-identical to FixelVariable.ttf and FixelVariableItalic.ttf upstream.
Axes: wght 100–900, wdth 75–100. Width 75 corresponds to Text and width
100 to Display. The site's initial preview uses weight 400 and width 100.
The italic font's fixed ital=1 axis is retained in the binary; a separate
italic face handles the preview, so no redundant ital slider is exposed.

Full variable WOFF2 files were converted from the original TTFs using
fontTools 4.66.1, with WOFF2 glyf/loca transforms disabled.
No subsetting or glyph changes were performed. The compressor removes only
the empty DSIG table (zero signatures), adjusts head.checkSumAdjustment,
and sets the required WOFF2 flag (head.flags bit 11).
All other decoded SFNT table bytes, including glyphs, cmap, names, license,
variation data and layout tables, were verified identical to the source.
